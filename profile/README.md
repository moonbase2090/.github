# Moonbase 2090

Moonbase 2090 LLC builds open-source developer tools. Public projects are
MIT-licensed.

## Public projects

- [**Prismattyc**](https://github.com/moonbase2090/Prismattyc) — a terminal application with built-in session management: tabs, split panes, named workspaces, and sessions you can detach from and reconnect to.
- [**Lightwell**](https://github.com/moonbase2090/lightwell) — maps the structure of Rust, TypeScript/JavaScript, Python, Go, and .NET projects: modules, imports, dependency edges, and product notes.
- [**Scorecard**](https://github.com/moonbase2090/Scorecard) — `sc`, a local code-quality gate that checks builds, tests, coverage of complex code, committed secrets, lint, and declared dependencies.
- [**Rookrunner**](https://github.com/moonbase2090/rookrunner) — a local worker and protocol for running builds and tests against captured source.
- [**cairn**](https://github.com/moonbase2090/cairn) — local-first shared memory for command-line agents, stored in a single SQLite file by default.
- [**agentkit**](https://github.com/moonbase2090/agentkit) — a Rust library for filesystem-defined agents with resumable sessions and tool calls.
- [**graphite**](https://github.com/moonbase2090/graphite) — the renderer-agnostic Graphite look and terminal UI widgets.
