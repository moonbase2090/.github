# Security

If you believe you have found a security vulnerability in any Moonbase 2090
software, please report it privately in one of these ways:

- Email **security@moonbase2090.com**
- Use GitHub private vulnerability reporting: open the repository's
  **Security** tab and choose **Report a vulnerability**

Include:

- What you found and which component is affected
- Steps to reproduce
- Impact if you know it

Please do not open a public GitHub issue for security-sensitive reports, and
do not post secrets, private keys, tokens, or credentials in a public issue.
We will acknowledge your message and work on a fix.

A repository may have its own `SECURITY.md` with project-specific details;
that file takes precedence.
