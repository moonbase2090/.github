# Contributing

Moonbase 2090 projects are open source under the MIT License, but they do
not currently accept outside pull requests. Unsolicited pull requests may be
closed without review.

## What is welcome

- **Bug reports.** Open an issue with the bug report template. Include the
  version, your platform, steps to reproduce, and what you expected.
- **Feature ideas.** Open an issue with the feature request template and
  describe the problem you want solved.
- **Security reports.** Do not open a public issue. Follow
  [SECURITY.md](SECURITY.md).

## Forking

You are free to fork, modify, and redistribute any project under the terms of
its license (MIT). See the `LICENSE` file in each repository.

## Building

Build and test steps differ per project. See the repository's own README and
docs.

## Conduct

Everyone taking part in issues and discussions is expected to follow the
[Code of Conduct](CODE_OF_CONDUCT.md).
